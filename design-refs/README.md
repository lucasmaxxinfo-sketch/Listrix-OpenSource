# Design references

Owner-supplied reference artwork for the Listrix DJ-deck UI (shared via Google Drive,
downloaded into `CLAW/`).

- `Listrixlogo.jpg` — neon DJ-deck logo
- `ListrixDeck.jpg` / `ListrixDeck.png` — turntable deck screenshots (dark stage + neon glow)
- `ListrixScreen.jpg` — app screen reference

The app's CSS (`frontend/src/index.css`) and components (`DeckLogo.js`, `DeckStage.js`)
implement this look with pure self-hosted SVG/CSS — no paid assets or CDNs.
